A Sophisticated Software Modeler

StarUML is your professional tool for UML 2.x modeling on macOS. Create precise class, object, use-case, component, deployment, sequence, statechart, activity diagrams—and Entity-Relationship Diagrams (ERD) with intuitive crow’s-foot notation. Razor-sharp on Retina displays, with high-DPI exports.

Quick Edit Mastery

Streamline creation with shorthand styles. Generate elements and relationships instantly—sub-classes, supporting interfaces, and more—without tedious steps. Focus on design, not drudgery.

Extension Ecosystem

Discover and install extensions effortlessly via the Extension Manager. Pull from the official registry or GitHub. Open-source options let you fork, customize, and extend functionality to fit your workflow.

JSON-Powered Simplicity

Models saved in clean JSON format. Pair with mdgen and EJS templates for seamless custom code generation. Lightweight, portable, and ready for automation.

Version 7.1.0 Refinements

Now with GFM (GitHub Flavored Markdown) support in the Markdown editor. Resolved stereotype attributes, UMLNodeView flexibility, and more for enhanced precision.

How It Works

Step 1: Design with Precision

Open StarUML and start with UML or ERD diagrams. Drag elements, apply Quick Edit shortcuts for instant relationships.

Step 2: Refine and Extend

Install extensions from the Manager. Customize views, generate code via JSON exports and templates.

Step 3: Export and Share

Output high-DPI PNG/JPEG images or JSON models. Integrate with your dev pipeline effortlessly.

Step 4: Iterate Seamlessly

Edit Markdown notes with GFM support. Leverage updates like stereotype defaults for ongoing refinements.

Fully optimized for macOS, including Retina displays. Runs smoothly on Apple Silicon and Intel.

Yes, via open-source extensions on GitHub and JSON-based code generation.
